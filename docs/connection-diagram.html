TankPilot - connection map

Block-level map: power sources, 3.3 V, ESP32-C3, USB, ultrasonic, float and probe ports, with the optional HLK 230 V block.

Plan stage. Planned design, not a finished schematic or PCB: nets come from PLAN.md, pin names and footprints must be checked in EasyEDA and against datasheets. The optional HLK 230 V block involves mains voltage: engineer review before any mains power; use the 5 V adapter or USB if unsure.
