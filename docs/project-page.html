What is TankPilot?

TankPilot is a small Wi-Fi water-level node for overhead tanks, underground tanks, sumps and cisterns. It reads the water level with whatever sensor you have, turns it into a clear percentage, and reports it to Home Assistant through ESPHome. A simple Home Assistant automation can then start your pump when the level falls below a limit you choose (for example 20 %) and stop it when the tank is full.

The problem

Float switches only tell you "full" or "empty". Ultrasonic sensors give a nice number but fail with steam, foam or a dirty sensor face. Probe kits are cheap and rugged but only give steps. Most tank controllers lock you into one of them and into their own box with no smart-home link.

The idea

Put all three on one open board. Use the ultrasonic sensor for a smooth percentage, the stainless probes as a safety cross-check, and a float as a last resort. If one fails, TankPilot keeps working with the next one and tells you which source it is using.

Key features

Everything the board does, in plain words.

📏

Ultrasonic level

Header for JSN-SR04T, HC-SR04 and similar 5 V sensors. The 5 V echo signal is divided down to a safe 3.3 V for the ESP32-C3.

🧪

5-level probe port

COM plus five stainless probes (20, 40, 60, 80 %, FULL) on two screw terminals. The probes are driven with AC pulses through a capacitor, so no DC flows through the water and the metal does not corrode.

🔘

Float switch input

Dry-contact input for any float switch, with a pull-up, a series resistor, a filter capacitor and an ESD clamp for long tank cables.

🔁

Automatic fallback

Ultrasonic fails? It switches to the probes. Probes fouled? It uses the float. The active source is always sent with the level so you can see it.

🏠

Home Assistant ready

Runs ESPHome over Wi-Fi with encrypted API and OTA updates. Level %, source, distance, probe states and health flags show up as entities.

⚡

Auto pump start

A Home Assistant automation starts the pump below your set level and stops it at full, with minimum off time, maximum run time and a data-fresh safety check.

🌡️

Light and climate

Extra ports for an LDR light sensor and a DHT11 temperature and humidity sensor, handy for a shed or pump room.

🔌

Flexible power

5 V DC jack, a 2-pin 5 V screw terminal, USB-C, or an optional on-board HLK-5M05 module for 230 V AC. The sources are combined with Schottky diodes.

🛡️

Protected inputs

Resettable fuse and TVS diode on the 5 V input, ESD protection on USB and the float line, series resistors on every probe line.

💾

Native USB

Flash and read logs straight over USB-C: the ESP32-C3 has built-in USB, so no USB-UART chip is needed. EN and BOOT buttons on the board.

📦

Fits an IP67 box

The 94 x 70 mm board is sized for a 120 x 80 x 55 mm transparent IP67 enclosure, with cable-gland-friendly screw terminals on the edge.

🧰

Open and hackable

Spare header with GPIO, 3.3 V and 5 V, status LEDs, and a full set of docs: BOM, wiring, schematic guide and PCB floor plan.

How it works

From water to pump in three steps.

Measure

The ESP32-C3 reads the ultrasonic distance, the five probes and the float. It checks each source for health (valid readings, consistent steps).

Decide the level

It converts the best healthy source to 0-100 %, cross-checks it against the probes and reports the level, the source and any alert to Home Assistant.

Act

Home Assistant compares the level with your start and stop limits and presses the pump's Start or Stop switch. If the tank data is stale, it never starts the pump automatically.

Which sensor should I buy? For auto-start at a fixed level the stainless probes are the safest main sensor; the ultrasonic sensor is nicer for a smooth percentage and trends. The board takes both, so you can add the second one later.

Home Assistant entities

What you get in your dashboard.

From the tank node

  • Tank level (%)
  • Level source (ultrasonic, probes, float)
  • Ultrasonic distance (cm)
  • Probe 20, 40, 60, 80 and FULL states
  • Float state
  • Ultrasonic OK and Probes OK health flags
  • Sensor mode (Auto, Ultrasonic only, Probes only, Float only)
  • Empty and full distance calibration

Auto-start automation

  • Start below (%), default 20
  • Stop at (%), default FULL
  • Maximum run time and minimum off time
  • Tank auto mode on/off switch
  • Never starts the pump on stale data
  • Notification when the tank node is offline
  • Works with your existing pump start and stop switches

Safety. The optional HLK-5M05 section connects the board to 230 V AC, and a water tank is a wet place. Build the 5 V version first, use an IP65 or better box, keep mains wiring away from the probe cables, and have a qualified person review anything that touches mains. The probe circuit and the firmware have not been tested on real hardware yet.
